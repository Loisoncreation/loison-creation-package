LOISON CREATION - GUIDE D'INSTALLATION
===========================================

ETAPE 1 : INSTALLER LES DEPENDANCES
------------------------------------
Ouvrir PowerShell dans ce dossier et taper :

npm install

(Cela prend 2-3 minutes)


ETAPE 2 : LANCER L'APPLICATION
-------------------------------
Ensuite taper :

npm start

Le navigateur s'ouvrira automatiquement !
